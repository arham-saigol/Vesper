# Vesper

A minimal PDF reader built with Electron, Vite, and React.

## About

Vesper is a lightweight, modern PDF reader application that provides a clean and efficient reading experience.

## Tech Stack

- **Electron** - Cross-platform desktop application framework
- **React** - UI library
- **Vite** - Build tool and development server
- **TypeScript** - Type-safe JavaScript
- **PDF.js** - PDF rendering engine

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build the application
npm run build

# Build distributable
npm run electron:build
```
